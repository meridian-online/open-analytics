# Licence notices Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A descriptor whose licence asks for a notice carries it on its `licenses[]` entry, and `check_descriptors.py` refuses one that does not.

**Architecture:** A table of what each licence asks (`datasets/licence-notices.json`) drives a new rule 10 in `scripts/check_descriptors.py`, which reads every descriptor file under `datasets/*/`, published or not. SOC 2020's overrides gain the notice and its descriptors are regenerated by a local `arc run`. A guide, `docs/licence-notices.md`, writes down each source's lines.

**Tech Stack:** Python 3.12 stdlib (`json`, `re`, `unittest`), DuckDB 1.5.5 (Python), arc 0.2.1.

**Spec:** `docs/superpowers/specs/2026-11-14-licence-notices-design.md`

## Global Constraints

- Public repo: no Kata refs, no private repo names, no local paths in tracked files or commit messages.
- Notice keys on a licence entry: `x-attribution`, `x-changes`, `x-licence-text`. Nothing else.
- Requirement keys in the table, per identifier: `clause` (required, the licence text the entry is read from), `path`, `attribution`, `copyright`, `names_licence`, `changes`, `text_marker`. Any other key is exit 2.
- Identifiers and requirements: `OGL-UK-3.0` (path `https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/`, attribution, names_licence `Open Government Licence v3.0`); `Unicode-3.0` (path `https://www.unicode.org/license.txt`, attribution, copyright, names_licence `Unicode License v3`, text_marker `UNICODE LICENSE V3`); `Apache-2.0` (path `https://www.apache.org/licenses/LICENSE-2.0`, attribution, copyright, names_licence `Apache License 2.0`, changes, text_marker `Version 2.0, January 2004`); `CC-BY-4.0` (path `https://creativecommons.org/licenses/by/4.0/`, attribution, copyright, names_licence `CC BY 4.0`, changes); `CC0-1.0`, `other-pd`, `notspecified`: nothing.
- ONS attribution, verbatim: `Source: Office for National Statistics licensed under the Open Government Licence v3.0.`
- Committed SOC 2020 descriptors are the ones `arc run` wrote, never hand-edited. Build env: `~/scratch/arc-0.2.1/arc`, `ARC_DUCKDB_BIN=~/scratch/duckdb-1.5.5/duckdb`, `FINETYPE_DUCKDB_EXT=~/.duckdb/extensions/v1.5.5/osx_arm64/finetype.duckdb_extension`. Nothing is published.
- Markdown prose: one line per paragraph.

## Review Focus

1. A licence entry with `name` but the notice keys at the package level instead: refused, naming the entry, not passed.
2. A descriptor with two licences, one asking a notice and one not (`CC0-1.0` + `CC-BY-4.0`): only the CC BY entry is held.
3. `x-attribution` present but empty or whitespace: refused as missing.
4. The attribution present on the entry but changed in the description by one character: refused (verbatim containment).
5. `licence-notices.json` missing or unparseable: exit 2, not a silent pass.
